# Statistique pour la Data Analyse et la Data Science

## 📌 Présentation du projet
Ce projet est dédié à l’application des **techniques statistiques** pour l’analyse de données et la data science.  
Il permet de passer **de l’exploration des données à l’interprétation des résultats** en utilisant des méthodes statistiques classiques et avancées.

---

## 🗂 Contenu du projet

Le projet contient :

1. **Analyse descriptive**
   - Moyenne, médiane, variance, écart-type
   - Distribution des variables
   - Analyse des outliers

2. **Tests statistiques**
   - Test de normalité (Shapiro-Wilk, Kolmogorov-Smirnov)
   - Test d’hypothèses (t-test, ANOVA)
   - Test de corrélation (Pearson, Spearman)
   - Test du Chi-Carré pour variables catégorielles

3. **Visualisation des données**
   - Histogrammes, boxplots, scatterplots
   - Matrice de corrélation
   - Graphiques adaptés aux variables quantitatives et qualitatives

4. **Analyse avancée**
   - Régression linéaire simple et multiple
   - Régression logistique pour variables catégorielles
   - Interprétation statistique des coefficients et p-values

5. **Conclusion et insights**
   - Synthèse des résultats
   - Recommandations business basées sur les données

---

## 🛠 Outils utilisés
- Python 
- Bibliothèques Python :
  - `pandas` pour le nettoyage et manipulation des données
  - `numpy` pour les calculs statistiques
  - `scipy.stats` pour les tests statistiques
  - `matplotlib` et `seaborn` pour la visualisation
- Jupyter Notebook pour l’exécution interactive

---

## 📈 Objectifs du projet
- Appliquer les **principes statistiques** aux datasets réels  
- Identifier les relations significatives entre variables  
- Visualiser les données pour faciliter l’interprétation  
- Générer des **insights exploitables** pour la prise de décision

---

## 🧠 Ce que le projet montre
- Maîtrise des statistiques descriptives et inférentielles  
- Capacité à effectuer des tests statistiques correctement  
- Analyse et interprétation de données pour la **Data Science**  
- Présentation professionnelle des résultats avec visualisations
